# All Office files to PDF
## 대부분의 오피스를 pdf로 변경

- 리눅스만 가능
- bin 폴더와 hnc 폴더는 따로 업로드

## Installation

- `sudo add-apt-repository ppa:libreoffice/ppa`
- `sudo apt update`
- `sudo apt install libreoffice`
- `libreoffice --version` 
- `.so file java lib 추가`
- `패키지 네임 변경 금지`
- `https://github.com/Ablestor/office-converter-lib` <-
